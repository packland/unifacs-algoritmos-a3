# Apresentação — Módulo 5

Deck de slides (16:9) sobre o sistema de cadastro de produtos.

```bash
npm run dev          # abre o deck no navegador
npm run check        # valida composição, layout e contraste
```

No `dev`, use as setas para navegar; aperte `P` para abrir a tela da audiência
(é a aba que você compartilha no Meet/Zoom). As notas do apresentador ficam no
painel do apresentador.

Arquivos:

- `index.html` — os 8 slides, estilos e animações.
- `assets/fonts/` — EB Garamond, Inter e JetBrains Mono (com as licenças OFL).
- `vendor/` — GSAP e o runtime do HyperFrames, para funcionar offline.
