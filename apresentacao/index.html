✱ O que o módulo promete

Cinco operações, uma promessa

carregar() Lê o arquivo e monta a lista de produtos na memória
salvar() Grava todos os produtos no arquivo de uma vez
buscar(código) Devolve o produto, ou None se ele não existir
adicionar(produto) Guarda o produto se o código ainda não estiver usado
remover(código) Tira o produto pelo código

Se alguma coisa der errado, nada muda.

  • O código é maior que zero e não pode repetir.
  • Nome e categoria são obrigatórios e não podem ter ;.
  • As quantidades não podem ser negativas.
  • O sistema aceita no máximo 100 produtos.

Quando algo dá errado

01

Código inválido · Quantidade inválida · Nome do produto inválido

02

O produto não pode entrar ou sair

if len(self.__armazenamento.produtos) >= MAX_PRODUTOS:

if self.__armazenamento.buscar(codigo_produto) is not None:
    print("Produto já cadastrado")

03

O arquivo está corrompido

Código repetido no CSV (ValueError) · linha malformada

O programa para com erro e não grava por cima.

A ordem das checagens existe para isso: só grava depois que tudo passou.

Remoção

procura → confirma → tira → salva

A confirmação é s/n. Se a pessoa cancelar, o produto continua no estoque e o arquivo não é tocado.

src/armazenamento.py
def adicionar(self, produto):
    if produto.codigo_produto in self.__produtos:
        return False
    self.__produtos[produto.codigo_produto] = produto
    return True

def remover(self, codigo):
    return self.__produtos.pop(codigo, None) is not None

✱ Por que assim

Por que usei um dicionário

  • Dicionário, não lista Acha e remove pelo código sem varrer tudo, e o código não fica repetido.
  • CSV, não banco É simples, dá para abrir e ler, e não precisa instalar nada.
  • Ler uma vez, ao abrir Lê o disco menos vezes e todos trabalham sobre os mesmos dados.
  • Classe Estoque no meio O menu não precisa saber que existe um CSV por trás.

“O código do produto já é a chave.”

@property
def produtos(self):
    return list(self.__produtos.values())

O dicionário guarda pelo código; a lista sai como cópia.

✱ O que ganhei e o que perdi

O preço de escolher simples

O(1)
buscar

Não depende da quantidade de produtos.

O(1)
remover

Também vai direto pelo código.

O(n)
salvar

Reescreve todos os produtos.

O(n)
carregar

Lê todos na abertura.

O(1): tempo constante. O(n): cresce com a quantidade de produtos.

  • Toda alteração regrava o arquivo inteiro.
  • Se o programa fechar no meio, o arquivo pode ficar pela metade.
  • O programa não percebe se outra pessoa editar o arquivo.
  • A lista que os colegas recebem é uma cópia: mudar nela não muda o estoque.
  • Um arquivo corrompido faz o programa parar, em vez de seguir com dados errados.

Com 100 produtos, regravar tudo é barato. Com milhões, precisaria de um banco de dados.
